[[Props in Class Components:
What Are Props?
Props are arguments passed from a parent component to a child component in React.
They are used to pass data or methods to child components.
Props are read-only, meaning they cannot be modified by the child component.
Example:
jsx
Copy code
function Car(props) {
  return <h2>I am a {props.brand}</h2>;
}
function Garage() {
  return <Car brand="Ford" />;
}
In the above code:
Garage is the parent component.
The Car component receives brand="Ford" as a prop.

Accessed using this.props.
