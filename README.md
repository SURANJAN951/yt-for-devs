# YouTube Clone with Code Editor  

This project is a **YouTube clone** with video playback and an integrated **code editor** where users can:  
- **Save Code & Notes** within the editor.  
- **Search for videos efficiently**   
- **Use advanced features** like chunk streaming and performance improvements.  

## 📌 Features  
✔️ **Video playback** like YouTube  
✔️ **Code Editor** to write and save code  
✔️ **Note-taking feature**  
✔️ **Search functionality**
